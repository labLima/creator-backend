# Especificação de agentes Creator (proposta)

Este arquivo foi mantido como ponto de entrada compatível com links existentes. A especificação foi dividida em [docs/agents/README.md](agents/README.md), com links para arquitetura, papéis, subagentes lógicos e workflows propostos.

O fluxo implementado continua definido pelas ADRs 014, 017 e 018: Business → Planner → Writer → Artist → Reviewer, com entrega e persistência controladas pelo Creator. A proposta de quatro agentes e onze subagentes não substitui esses contratos.
